### O que o Nexus X faz

Um clique antes da partida e o PC fica só para o jogo: memória livre, disco limpo, internet com menos atraso e o Windows conferido.

| | |
|---|---|
| **Memória** | Libera a RAM presa pelos programas sem fechar nada e limpa os arquivos que sobram no disco |
| **Rede** | Ajustes que baixam o atraso da internet nos jogos |
| **Modo Extremo** | Ajustes profundos do Windows, um por um, com volta ao padrão quando quiser |
| **Segurança** | Procura minerador, acesso remoto escondido e brechas no Windows, e corrige com um clique |
| **Nexus Command** | Alt + N em qualquer lugar: abre jogos, programas e arquivos digitando poucas letras |

### Para quem é

Para quem joga e quer o PC rendendo tudo, sem precisar entender de configuração do Windows. Funciona no Windows 10 e 11.

### Feito com

Rust, React e Tauri: leve, rápido e fica quietinho em segundo plano enquanto você joga.
